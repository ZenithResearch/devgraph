# DevGraph ontology extension v0.1.0

Imports Zenith core v0.13.0 from ZenithResearch/zenith-ontology. Shared term definitions retain their existing IRIs and authored parent relationships. This extension initially adds no new class definitions; it carries the DevGraph operation and runtime profiles independently. Those profiles retain their v0.12 runtime contract metadata and bytes. This source split does not upgrade installed runtimes or existing client pins.
