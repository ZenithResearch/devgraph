# Devgraph ontology

The canonical current release is described in [publication.json](publication.json).
Run `devgraph ontology` to inspect its version and discovery metadata.

Versioned bundles under `releases/` and their packaged mirrors are immutable
contracts. Their hashes are preserved in this public source snapshot. Some early
documents contain historical issue numbers and URLs from the original private
development repository; those are provenance text, not public support links or
requirements to access a private tracker. Current behavior is documented in the
[programmer guide](../docs/user/programmers.md), [Work contract](../docs/named-work-v1.md)
and [Arena contract](arena-runtime.md).
