# Zenith core v0.13.0

Continues the Zenith ontology last authored in DevGraph v0.12.0. All 86 term records and their authored axioms are preserved. The ontology identity and term IRIs are unchanged. Source stewardship moves to ZenithResearch/zenith-ontology.

DevGraph maintains a separate extension and runtime contracts importing this exact core release. Historical DevGraph releases and existing Zendo imports remain available unchanged. Directory vocabulary is retained here until a separately versioned Rolodex import migration. Existing shared-domain drafts, Product and library/publication modules retain their original maturity and namespaces. This source release does not change a runtime database or credential authority.
