# Organizational seats v0.10.0

Adds shared Seat, SeatType, SeatAssignment, CredentialPreset and
CredentialPresetRevision vocabulary. A Person or Agent occupies an organizational
seat; a seat type may suggest permission presets. Recipe revisions retain exact
permissions. Seat assignment and preset editing confer no authority. See seats.md,
seats.json and compatibility.md. This source release is not an installed runtime
upgrade or a claim of public web publication.
