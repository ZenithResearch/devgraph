# What Devgraph is

Devgraph is an internal work-graph Python package and HTTP service substrate.
It models structured work and evidence, persists graphs through memory or
Neo4j adapters, enforces scoped operations through an injected verifier,
records local mutation receipts, and exposes a read-only operator monitor.

The repository is not a hosted service, identity provider, public portal,
external event network, or direct Neo4j client API. See the [current-state
limits](../current-state.md).
