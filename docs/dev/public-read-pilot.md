# Public read pilot

`devgraph.public_read_runtime:create_app` is an opt-in, bounded HTTPS pilot around
the real v5 signed-read composition. It is not a general deployment installer or
production-hosting qualification. Supply separately reviewed private runtime,
membership trust, retained storage and secS configuration; none is generated by
this module. Use a dedicated listener and database for a first remote test.

The listener requires `DEVGRAPH_PUBLIC_ORIGIN`, `DEVGRAPH_PUBLIC_NAME` and
`DEVGRAPH_PUBLIC_EXPIRES_AT` (no more than three hours ahead), plus the existing
`DEVGRAPH_SIGNED_READ_CONFIG` / `DEVGRAPH_DATA_ROOT` / Neo4j environment. The signed
receiver must match the exact public HTTPS origin. Use TLS on the tunnel's upstream
connection too, verify its certificate, and disable HTTP request inspection. Do
not trust client-supplied forwarding headers or open database ports.

The default boundary exposes static monitor assets, public connection discovery,
holder-bound read enrollment/requests, and member access request/status only.
It rejects Work mutation, operator, generic query, database, docs and OpenAPI
paths before dispatch. Exact Host/TLS/Origin checks, a64KiB body cap,10-second body
deadline,8 concurrent requests,120/minute global refill and60-request burst bound
unauthenticated resource use. This global budget intentionally avoids spoofable
forwarded source-IP identities; it does not claim distributed DDoS protection.

Discovery is `GET /.well-known/devgraph-connection.json`. It contains only name,
receiver, issuer and public authority pin, compatible with existing Zenith iOS
connection files. Fetching it creates no trust, request, assignment or credential.
Native clients review it before saving, then use their own holder/installation
proof. No local credential is copied to a remote client. Existing grants remain
bound to their original origin and cannot silently migrate to this one.

## Separately approved operator review

Operator routes stay closed unless deployment explicitly sets
`DEVGRAPH_PUBLIC_OPERATOR_POLICY_SHA256` to the SHA256 of the reviewed canonical
operator-policy JSON. Enabling this is a separate security-sensitive deployment
choice: obtain explicit approval of the public operator surface and exact
operator keys/ceiling before setting it. The policy must be read-only, explicitly
object-scoped and end within the pilot window. The digest is checked at startup
and on every operator request; changes close that surface. These routes still
require the existing operator Wallet proof and signed review/final decision.
A member request does not confer operator authority or grant access. The v6 Work
mutation composition is never accepted by this listener.

For ngrok, use its official agent with HTTP inspection disabled and verified
HTTPS upstream; keep account tokens and local runtime configuration outside source.
Tailscale Funnel is another public ingress option; ordinary Tailscale Serve stays
private. Neither replaces secS/Wallet authentication. Do not alter existing Serve
or Funnel routes as a side effect of configuring this listener.

Tests: `pytest tests/native_read/test_public_read_runtime.py -q` checks default
closed routes, explicit opt-in closure, forged forwarding headers, wrong receiver,
expiry and resource bounds. Run native read tests with the pinned real secS binary.
Source checks and a tunnel health probe do not establish physical iPhone reads,
correct mobile membership, revocation, durability, availability or backup posture.
